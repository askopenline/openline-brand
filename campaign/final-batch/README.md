# Final batch

Twenty cinematic travel stories, with narrated everyday uses for mobile data and Openline travel eSIM planning.

AI-generated travel scenes and synthetic narration. Fictional situations, not customer testimonials or proof of local network availability.

## Package overview
- 20 vertical films (IDs: final-ad-01 to final-ad-20), each 22.08 seconds, 1080x1920 H.264/AAC.
- Each film features two unique native-speed 8-second AI-generated scenes, one continuous synthetic narration pass, word-pop captions, followed by 6.08 seconds of user-supplied white Openline icon animation. The outro animation displays, from top to bottom in three equal stacked layout zones on orange: (1) the moving original icon, (2) a stationary QR code linking to https://openline.com, and (3) stationary white openline.com text. The QR code and domain text are not part of the moving icon animation.
- Persistent AI badge; 'Generated by' text appears adjacent to the badge for 1.2 seconds. The AI badge remains at 70% opacity after 2 seconds.
- Files included:
  - mp4/: Video exports
  - posters/: Key frame images
  - captions/: SRT, VTT, and audio-derived word timestamp files
  - storyboards/: JPEG contact boards
  - storyboards.json
  - manifest.json (includes UI intro)
  - qa-summary.json
  - public-files.json (authoritative public whitelist)
- All exports decoded and reviewed: QR codes sampled (including last frame), audio loudness and true peak measured, narration transcribed and reviewed, and all review clips inspected via OpenRouter with targeted repairs.
