# Openline Brand Library v2.8.3

Recommended listing text is now editable by hand in the app (/app?version=recommended). Each field (Apple name, subtitle, promotional text, keywords, description; Google title, short and full description, and the rest) is a text box with a character counter, an Edited badge, a per-field Reset, and a "Restore all text" button.

Edits save in the browser under a separate key, like review notes. Store previews, copy buttons, downloads and the exported review use the edited text. Final, V1-V3, the original recommended copy defaults and the main saved workspace state are unchanged. Cache-busting updated to ?v=2-8-3.
