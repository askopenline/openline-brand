# Openline Brand Studio v1.15.0

The attached Brand Studio preview adds a presenter comparison and README-based motion remixes. Main mobile and store-preparation views remain intact.

## Included

- **Gary:** 7.2-second male-voice character test, 1920 × 1080 and portrait MP4, JPEG posters and captions.
- **Hellen:** three approximately 2.93-second visual options, all saying only “Hi, I'm Hellen for Openline.” in the same voice.
- **README motion:** faithful 3.04-second MP4 conversion, eight-second extension and 2.6-second sting, with GIF/JPEG exports and original WAV sound effects for the new remixes.
- **Downloads:** complete collection, individual presenter and remix packs, existing logo, ad and original motion resources.
- **Compatibility:** old Hellen pilot URLs and ZIP now serve the neutral version. The retired location-specific video is excluded from active packs.

## Quality and provenance

Presenter media is explicitly fictional/AI-generated. Gary's lower-third layout covers spurious generated lettering. Hellen 03 required one retake and lower-body clean-plate compositing; face and speech remain animated. Raw generation sources are preserved for editing and are not approved exports.

Automated audio-input review transcribed all four final presenter tracks correctly and described the new SFX as quiet with distinct soft beeps. Full video decoding, sampled frame review, browser playback, responsive layouts and archive navigation were checked. See `QA-v1.15.0.md`.

The approved 43.5% app icon is byte-identical to v1.14.0. No store screenshot, metadata edition or compliance gate was changed.

## Scope

This is a review collection, not the complete 60–90-second installation tutorial. The tutorial still requires a presenter selection, verified iPhone capture and product-specific activation timing.

The connected account reports READ access to `askopenline/openline-brand-assets`. This release is not a GitHub push or a deployment to the existing Fly site; it is the attached preview update.
