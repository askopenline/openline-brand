## Interactive QA

- Desktop 1440px and mobile 375px layouts inspected; no horizontal document overflow.
- All three preview modes and all five directions work.
- Four listing brand tabs and both platform controls select matching source assets.
- Compare-frame control loads corresponding Openline and competitor screenshots.
- All-five mode exposes 30 frames for the active platform.
- Image dialog supports previous/next, arrow keys, Escape, focus restoration
  and a contained tab sequence. Openline full PNG and reference-source links differ.
- Shortlist and notes export in schema 4; import restores both without marking
  a direction approved. The final 43.5% icon stays locked.
- Light and dark mobile layouts inspected; no client-side errors observed.
- Store listing copy uses the editable workspace fields. Install controls are
  decorative and clearly inside an illustrative store shell.

## Boundaries

Store shells approximate layout, not exact operating-system rendering.
Actual competitor screenshots are observed US-English listing assets dated
7 October 2026. Google reference images retain their lower source resolution.
Openline images remain design references with sample values; visible prices,
coverage, claims, setup flows and account features require native verification.
No native binaries, store submissions or compliance approvals are implied.
