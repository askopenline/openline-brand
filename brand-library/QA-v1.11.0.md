# Openline v1.11.0 QA checklist

- iPhone and Android final screenshot headline and subhead are neutral.
- Preview-on-iPhone CTA opens Apple device mode; Android CTA opens Android mode.
- Each device preview has six app views, working selection and previous/next.
- App Store / Google Play CTAs set the correct store and Openline brand.
- Fresh-load hash links resolve to the correct mode and platform.
- Complete-resource ZIP contains current PNGs, icons, native resources, sources
  and all named handoff documents, with no competitor screenshots.
- Desktop/mobile viewport fit, light/dark, keyboard focus and dialog behavior.
- Build, asset dimensions, metadata limits and archive integrity.
- Live Fly revision, PNG and download hashes verified after deployment.

No native app execution or store acceptance is claimed.
