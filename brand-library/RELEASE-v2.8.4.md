# Openline Brand Library v2.8.4

/app now opens on Current (the Recommended edition) by default. Final draft, V3, V2 and V1 sit behind a single Archives menu, on every version of the page.

Listing text and review notes use larger auto-growing text boxes with a Large editor for focused rewriting, character counters, and a "recommended original" comparison for edited fields.

A Share and export panel at the bottom of the page offers a link (selection plus edited listing text, never private notes), a ZIP with a readable summary, JSON, and the current listing text for both stores. The JSON can be imported back. Cache-busting updated to ?v=2-8-4.
