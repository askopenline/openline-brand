# Openline app screenshots V2

V2 is an alternative design-review edition, not a replacement for the original V1 assets or a claim of store approval. The app library and studio let reviewers switch versions.

## Contents

- Twenty-four screenshots: six marketing and six submission frames for each phone platform.
- Apple: 1320 × 2868 PNG masters; Google: 1080 × 1920 PNG masters.
- WebP previews, contact sheets, Google feature graphic and store-copy drafts.
- Six adapted app-resource captures: destinations, settings, installation profile, eSIM collection, usage dashboard and duration selection.
- Icon: the original vector mark scaled by 1.125 around the center of the same 1024px tile. The nominal artwork width changes from 43.5% to 48.9375%; this is a relative 12.5% enlargement, not a 12.5-percentage-point addition.
- White and transparent icon variants in SVG, PDF, PNG and WebP; white JPEG. Raster sizes: 1024, 512, 256, 128 and 64px.

## Design changes and boundaries

Amounts, currency symbols, price groups, payment/checkout controls, value badges and monetary copy are removed from the derivatives. The settings screen replaces the purchase-confirmation frame. Historical V1 screenshots and icon exports are untouched.

These app views are edited derivatives of the supplied React design resources, not captures from released iOS or Android builds. The source app is not changed. Do not use this edition to conceal differences from the shipping product: replace references with accurate native captures before submission.

Marketing and submission editions intentionally share the same neutral six-frame story; their panel border treatments differ. No comparative price or network-performance claim is introduced.

## Release checks still required

Verify the illustrated features, destination availability, plan durations, settings, activation instructions and usage information against the actual release. The shared design status bar is not evidence of native Android rendering. Check device slots and localization in the store consoles, and review the final release metadata and required commercial disclosures separately.

The enlarged icon is a V2 review alternative, not a silent change to the approved V1 native icon kits.
