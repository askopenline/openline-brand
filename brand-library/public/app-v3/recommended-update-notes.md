## Claims and evidence

Apple requires screenshots to show the app in use, while allowing text and image overlays; its separate creative-asset category does not make a standalone marketing illustration an app-in-use screenshot ([Apple App Review Guidelines, 2.3.3 and 2.3.14](https://developer.apple.com/app-store/review/guidelines/)). Google recommends actual in-app experience and restrained taglines, and discourages price/promotional claims in screenshot guidance ([Google preview-asset guidance](https://support.google.com/googleplay/android-developer/answer/9866151?hl=en)).

Openline’s setup guide specifies using Openline for data, leaving automatic data switching off and enabling Openline data roaming at the destination ([Openline installation guide](https://openline.com/installation-guide)). Apple documents separate voice/data lines and notes that carrier charges can still apply, so the copy does not promise the elimination of every home-operator charge ([Apple Dual SIM guidance](https://support.apple.com/en-us/109317)). Airplane-mode troubleshooting is omitted from this short setup excerpt.

The owner confirms 24/7 live chat and Openline advertises it publicly; this review did not test staffing or round-the-clock response ([Openline contact page](https://openline.com/contact)). The release app’s support link and the proposed support screen still need verification.

The owner’s cheaper-than-national-operator positioning is held for substantiation, not denied. Add dated comparisons matching destination, operator/plan, data allowance, duration and applicable fees before making that comparative claim. Consumer copy instead emphasizes avoiding unexpected data-roaming charges through a separate travel-data plan and appropriate device settings.

The existing installation guide also contains inconsistent activation-timing wording; this revision deliberately makes no calendar-activation or plan-start promise ([Openline installation guide](https://openline.com/installation-guide)).
