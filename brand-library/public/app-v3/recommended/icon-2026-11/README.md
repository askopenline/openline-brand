# Openline Recommended App Icon

Original vector paths, enlarged another 12.5% in width and height over V2, centered within the unchanged white square. Cumulative linear scale versus the original edition: 1.265625x (+26.5625%).

Use white 1024px PNG for the Apple icon resource and white 512px PNG for the Google Play icon resource. Store submission readiness requires separate validation.

Included: PNG and lossless WebP at 64, 128, 256, 512 and 1024px; SVG and vector PDF; 1024px white JPEG. White and transparent variants are separate. Transparent files are design resources, not store-upload icons; native Android adaptive layers are not included.

Only Recommended uses this edition. V1, V2, V3 and Final remain unchanged.
