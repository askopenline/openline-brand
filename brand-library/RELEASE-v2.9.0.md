# Release 2.9.0 - Final delivery v4

/app is now a single static delivery page for the App Store and Google Play, built from the proofread Recommended set.

- Store switch (App Store / Google Play, `?store=google`), with one-click copy for every listing field, live character counts and console paths.
- Category guidance, icon and graphics (primary and alternate), numbered screenshots in upload order, Google screenshot alt text.
- Pre-submission checklist: ticks saved per browser, open-only filter, Copy status, Reset, per-group progress and links back to the delivered asset.
- One ZIP per store: README, listing.md/json, category.md, checklist.md, graphics/, screenshots/WxH/NN-title.png.
- Removed: proofreading/editing workbench, version navigation and the Recommended/Final/V3 hub. Source preserved in the mirror repo tag `app-workbench-v2.8.7`. Archived public files are untouched.
- Reviewer notes are intentionally not part of the site or ZIP.
- Legacy `?version=` and `#/app` links open the delivery page.
