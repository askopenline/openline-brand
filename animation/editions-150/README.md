# Openline Motion Assets

This document details the motion assets available within the Openline brand library, accessible at [brand.openline.com/#/motion](https://brand.openline.com/#/motion).

## Motion Card Collection

The motion card collection has been expanded to 150 editions, adding 85 new editions to the existing 65. These 85 new editions are derived from 17 original synthesized sound families, each presented in 5 distinct layouts.

*   **Total Editions**: 150 (65 existing + 85 new)
*   **New Editions Structure**: 17 sound families x 5 layouts
*   **Dimensions**: 68 horizontal (1920x1080 pixels), 17 square (1000x1000 pixels)
*   **Duration**: The 85 new motion cards are each 12.16 seconds long, rendered at 50 frames per second. They consist of four original 3.04-second cycles.

These motion cards utilize exact source silhouette and timing, ensuring brand consistency without redrawn logos. Five layouts are shared, with arrangement differing for each edition.

## Asset Formats

For each motion card edition, the following assets are provided:

*   **Previews**: Five shared silent GIF previews.
*   **Posters**: JPEG poster images.
*   **Video**: MP4 video with AAC audio.
*   **Audio**: Lossless FLAC sound files.
*   **Metadata**: JSON event scores.

## Usage and Production

The motion assets are designed for various brand applications. The production files are located at `/library/productions/motion-150/` within the brand library deployment.

It is important to note that these 85 new editions represent variations of existing concepts and are not 85 original animation concepts. No new paid media generation is associated with this release.
