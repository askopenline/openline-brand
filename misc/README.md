# Openline Additional Assets

> Openline company documentation: maintained in [askopenline/openline-brand-assets](https://github.com/askopenline/openline-brand-assets). See the [repository README](../README.md) for ownership, scope, and release boundaries.

Company-maintained visual resources that do not yet belong to a dedicated asset
family. Before adding a file, check whether an existing logo, mobile, email,
social, or design-reference directory is a better home.

Use descriptive filenames and record source, intended use, and any third-party
rights alongside the asset. Review files for public disclosure before committing;
this directory is part of the public brand library, not a private inbox.
