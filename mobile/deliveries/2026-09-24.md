## Packaging decisions

- **Icons:** Preserve the native catalog, density folder names and PNGs. The icon pack contains 15 iOS PNGs and nine Android PNGs; `Contents.json` maps 18 iOS entries, with some sizes sharing a file.
- **Figma:** Preserve the original `.fig` bytes and extract its embedded thumbnail for the repository preview.
- **React:** Preserve component names and hashed image/SVG dependencies. Add a type-check command and ignore local dependencies/build output.
- **Preview:** Use a relative Vite base (`./`) and rebuild `preview/` so it can be hosted under a subdirectory, not only at a domain root.
- **Source fixes:** Add Vite's PNG import declarations and define the missing `ALL_PAYMENT_METHODS` demo registry from the 22 supplied logo components. Without this registry, opening the checkout method picker throws a runtime error.
- **Deep links:** Match exact screen names before partial names so `?screen=Me` opens the account screen, rather than the earlier `Payment success + code` screen.
- **Dependency maintenance:** Update Vite from 6.3.5 to 6.4.3 within the existing major version and refresh the lockfile in response to the dependency audit.
- **Documentation:** Keep the supplied implementation notes, add navigation and maintenance instructions, and distinguish mock UI from production functionality.

## Review boundaries
