# Openline Brand v2.4.0

This release, **Openline Brand v2.4.0**, significantly expands our motion graphics library and refines documentation, making it easier to integrate Openline branding into diverse applications and content.

## Motion Graphics Expansion

We've added **85 new motion graphic editions**, bringing the total to 150. These new additions are not 85 unique visual concepts but rather 85 distinct sound and layout variations of existing themes. The expansion includes 68 new horizontal (1920x1080) and 17 new square (1000x1000) formats, ensuring versatility across different platforms. All new animations are 12.16 seconds long, rendered at 50 frames per second, and built from four native 3.04-second visual cycles; complete audio editions are not promised to loop seamlessly. They are available in MP4/AAC, FLAC, JPEG, silent GIF, and JSON sound scores, catering to various production needs.

Key updates to the motion section include:

*   **New Filters**: Easily navigate the expanded library with new filters for 'all', 'new', and 'horizontal' content.
*   **FLAC Option**: Lossless FLAC audio is available for all 85 new editions.
*   **Quality Assurance**: All 85 new MP4s have been fully decoded and reviewed, with zero clipped audio samples and true peaks consistently between -5.19 and -4.77 dBTP. Automated audiovisual review covered 17 representative samples across all sound families and layouts.

Explore the full motion library at [brand.openline.com/#/motion](https://brand.openline.com/#/motion).

## Documentation and Guides

This release includes substantial updates to our documentation:

*   **Refreshed Content**: 20 existing documents have been refreshed for clarity and accuracy.
*   **Historical Annotations**: 41 existing documents now include historical annotations, providing context and evolution of our brand guidelines.
*   **New Guides**: Six new guides have been added, offering deeper insights into brand application.

Access the updated documentation on GitHub: [github.com/askopenline/openline-brand/tree/v2.4.0/docs](https://github.com/askopenline/openline-brand/tree/v2.4.0/docs).

## Other Content Updates

*   **Advertising Assets**: The library now features 40 active ads, including ten revised voiced stories with word-pop captions and spaced logo/QR/URL outros. View them at [brand.openline.com/#/ads](https://brand.openline.com/#/ads).
*   **AI Presenter Tutorial**: A new ~89-second continuous AI-presenter tutorial, explicitly illustrated, is available. This guide is not a genuine iPhone capture but a detailed visual explanation. Find it at [brand.openline.com/#/presenters](https://brand.openline.com/#/presenters).

## Fixes and Improvements

Several user interface and experience issues have been addressed:

*   Added a 24px desktop gap for tutorial buttons and improved stacked mobile actions.
*   Corrected inset dropdown arrows and reserved label padding for better visual consistency.
*   Removed obsolete GitHub pending-sync and read-only notices, streamlining the development workflow.

## Source and Assets

The 85 new Motion editions retain the original loading GIF's geometry and native animation speed. The approved app icon remains at 43.5% and is unchanged. No credentials, private payloads, or receipts are included in public deliveries.

### Release Assets

*   `openline-motion-85-editions-v2.4.0.zip`: Contains only the 85 new motion graphic editions.
*   `PUBLIC-ASSETS-v2.4.0.json`: A SHA256 manifest for the complete live public library.
*   `SHA256SUMS.txt`: A file containing SHA256 checksums for verification.

## Video previews and source checkout

The README now includes seven actual decoded video frames linked to their full MP4s: three Motion editions, three voiced ads, and Hellen's tutorial. Image provenance records capture times and SHA256 hashes.

The GitHub source archives include tracked code, artwork and documentation, not the entire multi-GB runtime media library. From `brand-library/`, run `python tools/hydrate-public.py` to inspect the manifest, then add `--download` to fetch the public files. Add `--prefix library/productions/motion-150/` to select only the new Motion assets.

## Review boundaries

The audiovisual review was automated, not a human listening session. New creative editions remain review candidates. Generated advertising scenes are not customer, app or performance evidence. The tutorial uses an illustrated installation guide rather than a real iPhone recording; native builds, real-device screenshots, legal disclosures and store acceptance remain separate submission gates.
